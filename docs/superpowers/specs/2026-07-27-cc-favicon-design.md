# C&C Detailing Favicon Design

## Goal

Replace the current rectangular wordmark favicon with a compact, legible `C&C` mark that matches the production website.

## Approved design

- Square black background matching the site’s dark palette.
- Bold italic white `C&C` lettering using the site’s Archivo typeface.
- One restrained red underline as the only accent.
- Tight optical spacing so the mark remains recognizable at 16, 32, and 48 pixels.
- No vehicle illustration, flag texture, phone number, border, gradient, or extra wording.

## Deliverables

- A scalable SVG favicon in `public/`.
- A PNG fallback suitable for browsers and pinned shortcuts.
- Updated favicon links in `index.html`.

## Verification

- Confirm the SVG and PNG render cleanly at favicon sizes.
- Confirm the production build includes both assets.
- Confirm the favicon links resolve after deployment.
